# hc12 · Rinse Reveal — Design

> Status: **Draft, written early**. Build order: **12th** (games are built in ID order).
> Route: **Open**. CrazyGames first, then Playgama, GameDistribution, GamePix, GameMonetize and YouTube Playables.

---

## 1. Concept

**The game in one line:** Power-wash the grime off everyday objects to uncover the bright hidden pattern underneath.

**Thumbnail idea:** One object split in half. The left half is caked in brown grime; the right half is freshly washed, wet and glossy, showing a vivid pattern. A spray of water runs along the dividing line. No text.

**What it should feel like:**
1. **The reveal.** Every stroke uncovers colour. The best moment is when the whole pattern appears at 100%.
2. **Calm, but still a game.** There is a water tank, so being efficient earns stars. Failing is gentle: you never lose progress.
3. **Wanting to collect them all.** Every cleaned object goes into a gallery, grouped into themed sets.

**Trend it rides:** power-washing and cleaning videos, which are a lasting "oddly satisfying" staple.

**How it differs from what already exists:**
- **Not a copy of PowerWash Simulator.** That game is 3D and first-person, you clean whole environments, and the reward is an object that's simply clean. Rinse Reveal is 2D, shows one object per level, and the reward is a **hidden design** coming out, more like a scratch card than a cleaning job.
- It uses its own UI, look and names. Nothing is borrowed from other cleaning games.

**Length:** a level takes 20–45 seconds. A session is 10–15 levels, about 5–10 minutes.

## 2. Art assets

**Visual approach:** almost everything is made in code. The only hand-made art is the object outlines.

| Layer | How it's made |
|---|---|
| Object shape | One flat outline (a silhouette) per object, stored as SVG |
| Hidden pattern | Generated by a shader, so there's no art to draw |
| Grime | A noise shader with a colour range for each grime type |
| Wet sheen and drips | A shader: wet areas darken and shine, then dry out |
| Water spray | Particles that all use one soft-circle texture |
| Background | A soft gradient for each theme |

## 3. How ads will work

All ad calls go through the **forge** adapter: `ads.break()`, `ads.rewarded(placement)` and `game.happy()`.

### Interstitial ads (`commercialBreak`)
- **Shown:** on the level-complete screen, after the reveal animation, when the player taps **Next**.
- **Never shown:**
  - before the first level, or during levels 1–3 (first impressions matter)
  - in the middle of a level
  - on retry
  - when the player has just watched a rewarded ad
- **How often:** at most one every 3 levels *and* at least 90 seconds apart. The portals also limit frequency on their side, so our limit is just a minimum spacing.

### Rewarded ads
| Placement | What the player gets | When it's offered | Limit |
|---|---|---|---|
| **Refill tank** | +50% water and carry on | The tank runs dry before 100% | Once per level |
| **Turbo for a level** | The turbo nozzle for this level | Before the level starts, on levels with tough grime | Once per level |
| **Double coins** | 2× the coins earned | Level-complete screen | Every level |
| **Find a sparkle** | Shows where a hidden sparkle is | During a level that still has unfound sparkles | Once per level |
| **Daily retry** | A second attempt at the daily challenge | Daily challenge result screen | Once per day |

Rewarded ads are always optional. Every button shows exactly what you'll get. If no ad is available, the button greys out instead of failing silently.

### Portal SDK events
| Event | When it fires |
|---|---|
| `gameplayStart` | The first touch in a level |
| `gameplayStop` | Level complete, pause, or an ad starting |
| `happyTime` | 100% reveal with 3 stars, and completing a set |
| Pause and mute | Audio and the game pause when an ad starts or the tab is hidden, and resume afterwards |
| Loading | Report loading progress, and signal "loading finished" when the menu is ready |

### Platform notes
| Platform | Notes |
|---|---|
| CrazyGames | Full Launch needs their SDK and ad requirements. Basic Launch (the test) can run without ads |
| YouTube Playables | Use the Playables SDK. Ads and pausing follow YouTube's rules. Keep the bundle under 15 MiB, which this game easily meets |
| GameDistribution, GamePix, GameMonetize, Playgama | Use each platform's driver in forge (or Playgama Bridge). Same placements as above |

## 4. Gameplay and progression

### Controls
- **Main control:** press and drag to spray. The nozzle appears slightly above your finger or cursor, so your finger never hides the spray.
- **Second control:** tap a nozzle button at the bottom of the screen to switch nozzles. Only shown once you have 2 or more nozzles.
- **Desktop:** hold the mouse button and move. Keys 1–4 switch nozzles.

### Core loop
1. A grimy object slides in.
2. The player sprays to clean it, and the **clean %** meter fills.
3. At 100%, the pattern pops with a shine sweep, a sparkle sound and confetti.
4. Stars and coins are shown, along with a rewarded "double coins" offer.
5. On to the next level.

### Mechanics
- **Water tank:** spraying uses water, and the gauge sits next to the meter. Every level gives at least 20% more water than a good run needs.
- **Grime hardness:** each grime type takes a different amount of spraying.

  | Grime | Hardness | Notes |
  |---|---|---|
  | Dust | 0.5 | Comes off in one quick pass |
  | Mud | 1.0 | |
  | Moss | 1.5 | |
  | Rust | 2.5 | |
  | Paint | 3.0 | |
  | Gum | Special | Blobs that only the Jet nozzle removes |

  Grime can be **layered**, for example mud over rust.
- **Nozzles,** unlocked as you progress:

  | Nozzle | Width | Strength | Water use |
  |---|---|---|---|
  | **Fan** (starter) | Wide | 1.0 | 1.0 |
  | **Jet** | Narrow | 2.5 | 1.2 |
  | **Turbo** | Medium, rotating | 3.0 | 1.8. **Damages delicate decals** |
  | **Soap** | Medium | 0 | 0.6 |

  Soap is a pre-treatment: it halves the hardness of whatever it covers, and you rinse with another nozzle afterwards.
- **Delicate decals:** from level 25, some objects have decals such as stickers or paintwork. Turbo spray on a decal chips it and costs a star. This gives a reason to switch nozzles.
- **Hidden sparkles:** 0–3 per level, hidden under the grime. Uncovering one plays a chime and adds a gem to your gems (the premium currency).
- **Cleaning combo:** a continuous stroke that keeps uncovering new dirt builds a combo (×1 → ×2 → ×3 coins). Lifting your finger, or spraying areas that are already clean for 0.5 s, resets it.
- **No pixel-hunting:** at 90%, the remaining dirty spots gently pulse. At 98%, the last specks wash off by themselves.

### Win, fail and star rating
- **Win:** the object reaches 100% (or 98%, when the auto-finish kicks in).
- **Stars:** based on how much water is left.

  | Stars | Water left |
  |---|---|
  | ★★★ | ≥ 35% |
  | ★★ | ≥ 15% |
  | ★ | Finished at all |

  A chipped decal costs one star, but you always keep at least one.
- **Soft fail:** when the tank runs dry, the player chooses **Refill (rewarded ad)** or **Retry**. Nothing is ever lost.

### Progression
- **Coins** come from levels, combos and stars. They buy upgrades:

  | Upgrade | Levels | Effect |
  |---|---|---|
  | Tank size | 10 | +5% water each |
  | Pressure | 10 | +5% strength each |
  | Combo duration | 5 | The combo lasts longer before resetting |

  The level generator scales the tank to the player's upgrades (see §5), so upgrades make levels *feel* easier and earn more stars, without ever breaking the difficulty curve.
- **Gems** come from sparkles and daily streaks. They buy cosmetics only: nozzle skins (gold, rainbow-stream, bubble), water colours and gallery frames.
- **Gallery:** every cleaned object is saved with its revealed pattern on a themed shelf. Finishing a set of 5 objects unlocks the next theme and a nozzle skin.
- **Daily challenge:** one object a day that's the same for everyone (seeded by date). Score = clean % per litre. There's a personal best and a **streak** counter.
- **Themes unlock by total stars,** not by level number. That way a player can't get stuck behind one level they can't 3-star.

### Tutorial (the first 10 levels)
| Level | Teaches |
|---|---|
| 1 | Small object, dust only, no tank. "Drag to spray." |
| 2 | Mud. The tank appears (with lots of water). |
| 3 | The first hidden sparkle. |
| 4 | Stars are explained. |
| 5 | An easy breather level. The first upgrade shop visit. |
| 6 | Moss. |
| 7 | The Jet nozzle unlocks. A gum blob that only Jet removes. |
| 8 | Two layers of grime. |
| 9 | Combo shown in the UI. |
| 10 | A "big" object (a mini boss), followed by the first set-complete celebration. |

## 5. Infinite levels and level progression

### What makes up a level
A level is fully described by a **seed** and a **difficulty number** `d`:

```
Level = {
  object:     pick(objectPool, seed, noRepeatWithin = 8)
  pattern:    pick(12 patterns, seed) + palette pick(8)   // 96 looks for each object
  grime:      1–3 layers, each = {type, noise seed, coverage %, hardness}
  tank:       waterNeeded(level, nozzles, upgrades) × slack(d)
  decals:     0–3 delicate zones (from level 25)
  sparkles:   0–3 positions in the dirtiest areas
  isBig:      every 10th level → larger object, more grime
  isBreather: every 5th level (when it isn't also a big level) → d − 2
}
```

With 30 objects × 12 patterns × 8 palettes × 6⁽¹⁻³⁾ grime combinations, that's **hundreds of thousands** of distinct levels. Adding content means adding one SVG outline at a time.

### Difficulty curve
- `d` climbs gently, plateaus, then repeats a sawtooth: `d(n) = log2(1 + n/4) × 3`, with breather levels taking −2 and big levels +1.
- The parameters that change with `d`:

  | Parameter | Easy | Hard |
  |---|---|---|
  | Grime layers | 1 | up to 3 |
  | Coverage | 60% | 100% |
  | Average hardness | low | high (rust and paint) |
  | Water slack | 2.0× | 1.2× (never below that) |
  | Decals | 0 | up to 3 |
  | Gum blobs | 0 | up to 5 |

- **Chapters** of 20 levels each use one theme's objects and palette. They loop through the themes, and the hardest grime types appear only in later chapters.

### Generator
- **Deterministic:** `seed = hash(levelNumber, "rinse-v1")`. The same level number always produces the same level, so the save only needs to store the level number, stars, gallery and wallet.
- **Always solvable:** `waterNeeded` adds up, for every grime cell, `hardness / bestNozzleStrength × waterUse`, then multiplies by a route factor of 1.3 to allow for overlapping strokes. The tank is set to `waterNeeded × slack(d)`, and slack is never below 1.2. So 3 stars is always reachable with the nozzles the player owns.
- **Measured against bots:** offline, a scripted bot plays 1,000 generated levels in a serpentine sweep. Any level where the bot can't reach 1 star gets its slack raised. This runs as a test in forge.
- **Variety guard:** no object repeats within 8 levels, and no pattern-and-palette combination repeats within 5.

### Hand-made levels
Levels 1–20 are written by hand in `levels.json` to keep the tutorial pacing exact. From level 21, the generator takes over.

### Adjusting difficulty when a player struggles
- If a player fails or retries the same level twice, raise its slack by 10%, up to +30%. This isn't shown to the player.
- If a player 3-stars 5 levels in a row, lower slack by 5%, never below 1.2.
- The adjustment is saved as a single number in the save file.

### Daily challenge seed
- `seed = hash(UTC date, "rinse-daily")`, with a fixed medium difficulty.
- Everyone gets the same object that day, which makes good shareable content for short videos.

## 6. As a mobile app

| Area | Plan |
|---|---|
| **Wrapper** | Capacitor (Android + iOS), using the same web build with forge's `app` driver |
| **Orientation** | Portrait only. Respect the notch with `env(safe-area-inset-*)` |
| **Touch** | The nozzle sits 60 px above the finger (can be switched off in settings). Two-finger tap = undo the last nozzle switch. No other gestures |
| **Haptics** | A light tick about every 80 ms while cleaning new dirt, nothing on already-clean areas. The difference feels great. A success buzz on 100%. A soft bump when a decal chips |
| **Performance** | The grime mask is 512² on phones (1024² on desktop). Cap the pixel ratio at 2. Clean % is read from a 32² downsample every 250 ms, never every frame. Aim for 60 fps on a mid-range Android phone from 2021 |
| **App size** | ~10 MB including the WebView shell. Works fully offline |
| **Ads** | AdMob rewarded ads in the same placements as §3, interstitials capped the same way. Google's UMP consent form (GDPR); App Tracking Transparency prompt on iOS |
| **In-app purchases** | **Remove ads** (interstitials only; rewarded ads stay available), a **gem pack**, a **starter pack** (gems + gold nozzle). Cosmetics only, never pay-to-win |
| **Saves** | Capacitor Preferences, using the same save format as the web build. Cloud save (Play Games / iCloud) can come later |
| **Notifications** | Opt-in only: one local reminder a day for the daily challenge and the streak. No push server |
| **Store listing** | Keywords: power wash, cleaning, satisfying, ASMR, relaxing, reveal. Screenshots: the split dirty/clean view, the gallery and the daily challenge. Use a short gameplay clip as the preview video |

## Build notes

### Key implementation decisions
- **Rendering:** a three.js orthographic camera with one full-screen quad for the object.
- **Grime mask:** a pair of render targets that are swapped every frame. Each pixel stores:

  | Channel | Stores |
  |---|---|
  | R | Remaining hardness of the top grime layer |
  | G | Remaining hardness of the second layer |
  | B | Remaining hardness of the third layer |
  | A | Wetness, which fades back to dry over time |

  Each frame, a brush shader subtracts `strength × dt` along the spray path. The path is interpolated between frames so fast strokes don't leave gaps.
- **Drawing the final image:** the object outline (rasterised from SVG into a texture) cuts out the pattern from the pattern shader. The grime colour sits on top wherever the mask is above 0, with darkening and highlights where things are wet, plus decal and sparkle textures.
- **Clean %:** shrink the mask down to 32² on the GPU and read it back every 250 ms. **Never read the full-size mask back to the CPU.**
- **Water tank use** is worked out on the CPU from the nozzle and spray time. It doesn't depend on what's on screen, so it's always accurate.
- **Shared with forge:** everything that isn't specific to this game. That includes saves, ads, i18n, audio, UI, the generator seed tools and the bot test harness.

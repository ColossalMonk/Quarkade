Koi Out level editor

Level JSON (LevelDef). w, h; cells are y·w + x. koi: {c: [cells, head first], d: 0 up / 1 right / 2 down / 3 left} (for koi of 2+ cells, d points away from the second cell). Optional pads, reeds (cell·4 + dir of a closed exit), frogs [cell, count], whirls, currents [cell, dir]. sol: an escape order (koi indices). Koi colours use the first journal page.
